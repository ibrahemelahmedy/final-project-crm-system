## إزاي تضيف مشكلة جديدة

اعمل ملف جديد بالرقم اللي بعد الآخر، وحط فيه الأقسام الخمسة دي:

```markdown
# NNN — عنوان قصير للمشكلة

**الحالة:** 🔴 مفتوحة / ✅ متحلّة / ♻️ بتتكرر
**التاريخ:** YYYY-MM-DD
**الخطورة:** حرج / متوسط / بسيط

## إيه اللي شفناه
(العَرَض زي ما ظهر — رسالة الخطأ الحقيقية، مش وصف تقريبي)

## ليه حصل
(السبب الجذري)

## الحل
(الخطوات، أو الكوميت اللي صلّحها)

## الدليل
(مسار ملف، رقم كوميت، أو مخرجات أمر — عشان حد يقدر يتأكد بنفسه)
```

بعدها **حدّث الجدول فوق** — الملف ده هو الفهرس، لو مش فيه المشكلة كإنها مش موجودة.
