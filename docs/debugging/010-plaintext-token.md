# 010 — توكن Jira مكتوب صريح في ملف غير محمي

**الحالة:** 🔴 مفتوحة
**الخطورة:** 🔴 أمني
**اتلاحظت:** 2026-08-24 · **اتراجعت:** 2026-09-02

## إيه اللي شفناه

توكن Jira API مكتوب **نص صريح (plaintext)** في:

```
docs/requirements/required-for-System-ERP/data.txt
```

الملف ده بره أي حماية — مش متغطي بـ `.gitignore`، ومش في المكان المخصص للأسرار.

## ليه ده مهم

توكن Jira API بيدّي **صلاحية كاملة على حساب Jira** — قراءة وكتابة كل الإيشوز والمشاريع.
مش مجرد "قراءة".

## الوضع الحالي (مراجعة 2026-09-02)

| الموقع | الحالة |
|---|---|
| `.squad/secrets.yaml` | ✅ **آمن** — متجاهَل في `.gitignore:2`، ومش متتبَّع في git خالص |
| `docs/.../data.txt` | ⚠️ **لسه مكشوف** |
| التوكن نفسه | 🟡 **مرفوض أصلًا (401)** — [شوف مشكلة 001](001-jira-token-401.md) |

الخبر الحلو إن التوكن المكشوف ده **بطل يشتغل** لوحده (منتهي أو ملغي).
فالخطر الفوري أقل — بس ده حظ، مش تأمين.

## الحل

### 1. ألغِ التوكن رسميًا

من **https://id.atlassian.com/manage-profile/security/api-tokens** — لو التوكن ده لسه ظاهر
في اللستة، اعمله **Revoke**. متعتمدش على إنه "منتهي".

### 2. شيله من `data.txt`

امسح السطر من الملف، أو انقل الملف لمكان بره المستودع.

⚠️ **لو الملف كان اتعمله commit قبل كده**، مسحه دلوقتي **مش** بيشيله من تاريخ git.
اتأكد الأول:

```bash
git log --all --full-history -- "docs/requirements/required-for-System-ERP/data.txt"
```

لو طلع نتايج، التوكن موجود في التاريخ ولازم يتلغى من Atlassian (الخطوة 1) — تنضيف
تاريخ git شغل منفصل وأصعب.

### 3. المكان الصح للأسرار

`.squad/secrets.yaml` — متجاهَل في git ومحمي. أي توكن جديد يروح هناك، مش لملف توثيق.

## الدليل

```bash
git check-ignore -v .squad/secrets.yaml
# .gitignore:2:.squad/secrets.yaml	.squad/secrets.yaml

git ls-files --error-unmatch .squad/secrets.yaml
# error: pathspec ... did not match any file(s) known to git   ← مش متتبَّع ✅
```

## درس مستفاد

الأسرار بتتسرّب لملفات التوثيق أكتر ما بتتسرّب للكود — لأن حد بينسخ مخرجات terminal
أو خطوات إعداد ونسي إن فيها توكن. أي ملف `.txt` فيه خطوات إعداد يستاهل نظرة.
