Wisal Chat Widget — Demo

This is a deliberately plain static page — no build step, no framework, no bundler. It exists to prove Story 26's (WIS-22) Done Criterion 3: a chat widget can be embedded on any third-party page with a single <script> tag, no CORS change, and no CSP exception. The tag below loads /widget.js, which injects a launcher button and an iframe pointed at the unauthenticated /widget/chat route of this same deployment.

Click the chat button in the corner of this page to open the widget. It calls the API same-origin through the Vercel/Vite proxy — nothing here talks directly to the API. 

<script
  src="https://your-wisal-deployment.example/widget.js"
  data-site-key="demo-site-key"
  data-origin="https://your-wisal-deployment.example"
  data-title="Chat with us"
></script>

The real data-site-key comes from an Administrator's Channels screen after connecting the Chat channel; data-origin is the origin this Wisal deployment is served from.
